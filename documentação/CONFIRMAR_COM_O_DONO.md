# Confirmar com o dono antes de publicar

Checklist para a conversa com a barbearia. Tudo que está aqui aparece no código como `CONFIRMAR` ou `TROCAR`.

- [ ] **Horário de funcionamento.** Hoje está "segunda a sábado, 10h às 20h" como estimativa. Confirmar dias, horários e se tem intervalo.
- [ ] **WhatsApp.** O número (11) 94729-6481 é WhatsApp mesmo? Quem responde?
- [ ] **Equipe.** Nome do segundo barbeiro (o outro é o Marcos) e fotos dos dois.
- [ ] **Preços.** Os valores vieram do Booksy. Continuam os mesmos?
- [ ] **Combos.** O Booksy lista 11 combos e só 5 estão no site. Quais os outros 6?
- [ ] **Formas de pagamento.** O JSON-LD diz "Dinheiro, Pix, Cartão". Confirmar.
- [ ] **Coordenadas.** Latitude/longitude no JSON-LD e nas metas `geo` são aproximadas. Pegar a exata no Google Maps (botão direito no pin → copiar coordenadas).
- [ ] **Fotos do portfólio.** 8 fotos de cortes (ou puxar do Instagram com autorização).
- [ ] **Link de avaliação.** Link "Pedir avaliações" do Perfil da Empresa no Google.
- [ ] **Autorização.** OK do dono para publicar o site com nome, endereço, fotos e preços.
- [ ] **Link no Google.** Combinar de colocar o link do site no Perfil da Empresa, na bio do Instagram e no Booksy.
